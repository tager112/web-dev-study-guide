IT.115 & DEV.140 Week 2 (Lectures 3 & 4)

Labeling Moving Boxes & Navigating Folder Doorways

Every HTML5 page begins with <!DOCTYPE html>, invisible browser instructions inside <head>, and visible content inside <body>. Inside <body>, semantic tags label your moving boxes: <header>, <nav>, <main> (only 1 per page!), <section>, and <footer>.

🧭 The 3 Relative File Path Rules (Lecture 4):
  • Same folder: Just the file name → href="about.html"
  • Step INTO a folder: Folder name + slash → href="pages/projects.html"
  • Step OUT of a folder: Two dots + slash (../) → href="../index.html"

🕵️ Lecture 20: The 4 Debugging Questions (In Exact Order)
  1. Is every file loading? (Network tab, refresh → check for red 404s like leading /assets/... or uppercase About.html)
  2. Is there red in the Console? (Read first line → e.g. null because <script> was in <head> instead of end of <body>)
  3. Which CSS rule is winning? (Inspect element → check crossed-out rules & specificity: #id > .class > type)
  4. What's too wide at 320px? (Device mode 320px → fix sideways scroll with img { max-width: 100%; height: auto; })
